# ADR-0005: Elección de un framework para el desarrollo de la API REST

> ESTADO: ACEPTADO

## Contexto

Necesitamos un framework de Python para poder crear y gestionar la API REST.

## Decisión

Usaremos FastAPI + Pydantic

## Consecuencias

- Son las herramientas que usaron los profesores para su código de la API REST.
- FastAPI es una librería de Python y es conocida por su sencillez.
