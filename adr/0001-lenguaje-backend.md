# ADR-0001: Elección de lenguaje de programación para desarrollar el backend

> ESTADO: ACEPTADO

## Contexto

Necesitamos un lenguaje que nos permita desarrollar el backend (incluyendo funcionalidades relacionadas con API REST y PLN) de la manera más sencilla posible.

## Decisión

Usaremos Python 3

## Consecuencias

- Todo el equipo está familiarizado con este lenguaje.
- Amplio ecosistema de librerías.
- Facilidad de integración con herramientas de IA.
- Los profesores nos han proporcionado código y tutoriales hechos en Python.
