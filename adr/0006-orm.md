# ADR-0006: Elección de un ORM

> ESTADO: ACEPTADO

## Contexto

Necesitamos un ORM de Python para poder hacer queries a la base de datos en los endpoints de la API REST de manera agnóstica al sistema gestor de base de datos.

## Decisión

Usaremos SQLAlchemy

## Consecuencias

- Es una librería conocida de Python.
