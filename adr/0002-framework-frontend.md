# ADR-0002: Elección de framework para desarrollar el frontend

> ESTADO: ACEPTADO

## Contexto

Necesitamos un lenguaje o framework que nos permita desarrollar el frontend, integrando la API REST del backend, de la manera más sencilla posible.

## Decisión

Usaremos Vue 3 + TypeScript

## Consecuencias

- Algunas personas del equipo están familiarizadas con Vue 3 + TypeScript.
- Vue 3 proporciona herramientas para un desarrollo frontend más rápido respecto a JavaScript puro.
- TypeScript se integra bien con las interfaces de los endpoints de la API REST.
